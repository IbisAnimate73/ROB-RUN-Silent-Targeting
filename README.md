# ROB RUN Silent Targeting

Download: soon

Silent targeting: shots redirect to the target without moving the crosshair.

## Modes

**silent** — pure redirect, fastest, most obvious.
**visual** — crosshair travels, readable on capture.

| Setting | Default | Range |
| --- | --- | --- |
| fov | 10° | 2-35 |
| hitchance | 80% | 30-100 |
| delay | 10 ms | 0-50 |
| fallback bone | chest | head/chest |

## Believable settings

Hitchance 80 and FOV 10 with a 10 ms delay reads almost clean. Visual mode plus high smoothing is the capture-friendly variant.

## Install

Extract, administrator, game, INSERT, F5 toggles. Bind a separate key for mode switch if you swap often.

## Troubleshooting

Misses at range: hitchance up. Double fire: delay up. No trigger: F5 and key check.

## Notes

Silent does not fix fire rate, it only redirects. Windows 10/11, Steam, EAC.
